# ds-portfolio

Anjay Sah - CSC2180 Data Structures Portfolio

1. Portfolio1A - Templated singly linked list (LinkedList)
2. Portfolio1B - Undo/redo text buffer using a custom Stack
3. Portfolio2A - Templated binary search tree (BST)
4. Portfolio2B - Contact directory backed by the BST

Each folder has its own Makefile, README.md, and REFLECTION.md. To build any part on ludwig.mcs.uvawise.edu, go into its folder and run `make`.
