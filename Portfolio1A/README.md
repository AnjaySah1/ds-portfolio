# Portfolio 1A - LinkedList<T>

## What I built
A templated singly linked list supporting pushFront, pushBack, popFront, remove, contains, size, isEmpty, print, the Rule of Three (deep copy), and a forward iterator for range-based for loops.

## How to build and run

make
./main

No input file or arguments needed. 'make clean' removes the compiled binary.

## Known limitations
-> No reverse iterator, only forward.
-> print() assumes the type T supports operator<<.
